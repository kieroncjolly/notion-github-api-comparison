# GitHub vs Notion API Comparison

A technical documentation project comparing the **GitHub REST API** and **Notion API** through hands-on API testing, JSON response analysis, authentication, pagination, and documentation research.

## What this project demonstrates

* Reading and interpreting API documentation
* Working with REST API requests and JSON responses
* Authentication and HTTP headers
* Understanding objects, properties, IDs, and relationships
* Pagination and handling API response data
* Comparing different API architectures and documentation approaches
* Turning technical findings into clear, structured documentation

## Evidence

This project is based on **actual API requests and responses**, rather than generated examples.

The documentation includes evidence from:

* GitHub API responses
* Notion API responses
* Postman testing
* Terminal/API testing
* JSON response analysis
* Official API documentation

## Selected comparison areas

| Area                | GitHub API              | Notion API                              |
| ------------------- | ----------------------- | --------------------------------------- |
| API style           | REST                    | REST                                    |
| Authentication      | HTTP headers / tokens   | HTTP headers / tokens                   |
| Data structure      | Resources and objects   | Pages, databases, blocks and properties |
| Pagination          | Cursor-based pagination | Cursor-based pagination                 |
| Documentation focus | Resource-oriented       | Content/property-oriented               |

## Why I made this project

The purpose was to practice a realistic technical-writing workflow:

**Research → Test → Capture evidence → Analyse → Compare → Document**

Rather than only explaining how APIs work, I tested the APIs and used the resulting data as the basis for the documentation.
